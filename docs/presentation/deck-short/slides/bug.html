7 / 9

The signal was a single JSON log line: itinerary_skipped with reason noITINERARY_BASE_URL. Root cause: the actor's umbrella telnyx.toml [env_vars] do not reach actor instances' process.env (a live platform finding, step 11), while the Cloud Storage bucket binding does. Fix: the MCP server forwards ITINERARY_BASE_URL, REMINDER_DELAY_SECONDS, SMS_FROM and SMS_PROFILE_ID on every saveDeal call inside the config field, and the actor resolves config.X ?? process.env.X. Evidence: itineraryUrl now returns, reminder_scheduled fires, and a check_itinerary.mts case with no process.env passes. Two more silent failures: TooManyObjects — the bucket's 5-object cap was hit during writes while live_check stayed green; fixed by only writing 4 slot keys + one audit/latest.json, with storage_check.py guarding the cap. And slow KV (commit 11bff7e): every call was degraded by 1.2–3.7 s REST reads; fixed by caching flags, running the session write after the response, and raising the webhook budget to 2500 ms.
