The hardest bug

The actor never saw its own config

Symptom

On save, the itinerary URL and the SMS reminder never appeared.

Signal

itinerary_skipped reason=noITINERARY_BASE_URL

Root cause

Umbrella telnyx.toml [env_vars] never reach actor process.env. The Cloud Storage bucket binding does.

Fix

MCP forwards config on saveDeal; the actor reads config first, process.env as fallback.

Evidence

itineraryUrl returns, reminder_scheduled fires, a check with no process.env passes.

Second silent failure: bucket's 5-object cap (TooManyObjects) hit while live_check stayed green; found in actor logs; fixed with 4 slot keys + one audit/latest.json; storage_check.py guards the limit.
