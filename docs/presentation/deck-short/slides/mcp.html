4 / 9

A fresh McpServer + stateless StreamableHTTPServerTransport (sessionIdGenerator: undefined, JSON responses) is created per request since Edge has no request lifespan. Bearer MCP_API_KEY is checked in handleRequest before the transport. Each tool resolves the caller from params._meta.telnyx_conversation_id → KV session/<conv_id> entity_id → env.SESSIONS actor, so phone numbers never appear in tool arguments. The flytlv client sends X-API-Key on every GET, times out at 3000 ms with one retry, and drops flights leaving within 3 hours via bookable(); weekend dates are computed server-side and country filtering runs after the fetch.
