Four tools: search_deals, save_deal, list_saved_deals, send_deal_sms. The server uses the official @modelcontextprotocol/sdk with a fresh McpServer + stateless StreamableHTTPServerTransport({sessionIdGenerator: undefined, enableJsonResponse: true}) per request — Edge has no request lifespan. Bearer MCP_API_KEY is checked before the transport; tool failures return {isError: true} with a caller-friendly message, never a traceback or URL. Each tool resolves the caller from params._meta.telnyx_conversation_id → KV session/<conv_id> → entity_id → env.SESSIONS, so phone numbers never appear in tool arguments. flytlv is GET /api/private/deals with X-API-Key, 3000 ms timeout + 1 retry on TimeoutError, and the bookable() filter drops flights leaving < 3 h (MIN_HOURS_BEFORE_DEPARTURE). Weekend dates are computed server-side (weekendDates("upcoming"|"following") → Thu/Fri/Sat dates).
