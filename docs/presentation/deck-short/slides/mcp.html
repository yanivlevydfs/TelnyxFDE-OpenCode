list_saved_deals

send_deal_sms

  • Official @modelcontextprotocol/sdk; a fresh stateless transport per request.
  • Bearer MCP_API_KEY checked before the transport; failures return isError: True with a caller-friendly message, never a traceback.
  • MCP tools can't be scoped per node, so each prompt node's text names its one tool.

Four tools, each backed by the caller's actor: search writes the results, save writes a page and schedules a reminder, list reads back saved ones, send texts a saved deal when SMS is on. We use the official SDK with a fresh stateless StreamableHTTPServerTransport per request, since Edge has no request lifespan. Tools can't be scoped per workflow node, so each prompt node's text names its one tool and the server enforces safety itself; failures return isError:true, never a traceback or URL.
