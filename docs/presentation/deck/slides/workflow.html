Speak nodes deliver the brand greeting and the three notices word-for-word with no model turn — the disclosure must not be paraphrased. Prompt nodes are every LLM-driven step: the routing hub, search, save, list, FAQ, the timeout escalation and transfer. The End Call node is a terminal tool node running a shared hangup tool, so no prompt node can hang up mid-conversation. In tests and dry runs the hangup node falls back to a prompt. Escalation and hangup replace the base instructions; the others append, to keep the model tightly on task.
