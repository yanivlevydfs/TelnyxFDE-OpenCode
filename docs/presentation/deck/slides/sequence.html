4 / 18

Read it top to bottom. At call start, Telnyx calls the webhook once. The webhook reads the flags from KV and calls recordCall on the caller's actor, which returns the full profile, and it answers with the dynamic variables. During the conversation the assistant calls MCP tools: search_deals checks the KV cache, calls flytlv only on a miss, and stores the results on the same actor. save_deal calls saveDeal on the actor and passes the config with it.
