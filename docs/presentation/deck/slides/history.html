Live since today. Each search and save goes through the MCP server to the caller's actor, which appends it to a searchHistory list capped at 50, and writes one immutable JSON file per event to Cloud Storage under audit, with the caller's number masked. Separately, Telnyx keeps every conversation, and an insight group called FlyTLV caller intent extracts the destinations, dates, saved deal and outcome after each phone call. scripts/ops/history.py puts the actor history and the Telnyx conversations and insights into one report per caller or per date. KV was the wrong tool: history needs a safe read-modify-write, and audit needs write-once files.
