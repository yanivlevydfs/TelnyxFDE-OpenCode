The webhook overrides the assistant's default variables at call start; if it fails entirely the defaults keep expression edges from comparing against raw placeholders. The 1.5 second platform default is too tight for a cold Edge start, so the assistant timeout is 8000 ms and the webhook keeps an internal 2500 ms parallel budget — the session write even runs after the response. On any actor or KV failure it returns backend_degraded=true, which routes the call to a scripted notice instead of reading placeholders on air.
